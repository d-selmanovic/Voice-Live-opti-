# Frontend-Regeln

Core-AGENTS.md beachten. Mikrofon, Playback und Verbindungszustand klar darstellen. Tatsächliche Hörzeit getrennt vom Transkript. Keine Zugangsdaten oder technische Autorisierung im Browser. Abbruch/Neustart verhindert veraltete UI-Ergebnisse. Erst Browserbasis, danach Telefonie.
