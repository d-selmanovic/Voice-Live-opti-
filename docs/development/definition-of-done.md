# Fertigstellung

Dokumentationsaufgabe: benötigte Inhalte statt Leerhüllen, funktionierende lokale Verweise, konsistente Anforderungen/Quellen/Issues, ehrlich markierte Grenzen, Prüfung und Git-Commit.

Funktionsaufgabe: beobachtbares Verhalten, passende Fehlerfälle, tatsächlich ausgeführte Tests, keine Datenvermischung, Anleitung reproduziert. Für Voice außerdem Audio- und Aufgabenqualität prüfen; Unit-Tests allein reichen nicht.

Produktionsfreigabe: zusätzlich Pilot-/Lastnachweise, Lizenz/Deployment, Zugang und Aufbewahrung, Wiederherstellung und Rücknahme. Eine vollständige Ordnerstruktur ist keine Freigabe.
