# Metriken und Messmethode

| Metrik | Messung |
|---|---|
| Aufgabenerfolg | erwarteten Zustand mit tatsächlichem Endzustand vergleichen |
| Faktenkonsistenz | Aussagen gegen zugelassene Quellen und Toolergebnisse |
| Regeltreue | Pflichtregeln und berechtigte Aktionen pro Szenario |
| Antwortzeit | Zeitpunkt beim Browser-Playback relativ zum festgelegten Anfrageereignis |
| Tooldauer | Executor-Start bis bestätigtes Ende; Timeout gesondert |
| Unterbrechung | Nutzerbeginn bis hörbares Ende/korrekte Wiederaufnahme |
| Natürlichkeit/Aussprache | menschliche Bewertung getrennt je Sprache/Stimme |

Erzeugtes Audio und Transkript beweisen nicht den Hörzeitpunkt. Schwellen, Messfenster und Samples vor Freigabe definieren; p50/p95 nur mit ausreichenden Beobachtungen berichten.
