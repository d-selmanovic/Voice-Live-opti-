# Tool ergänzen

Bedarf und Auftrag bestimmen; Eingabe-/Ergebnisvertrag, Freigabe und Bestätigung definieren. Executor mit Zeitlimit, eindeutiger Operation, Revision und Fehlerstatus entwickeln. Unzulässige und doppelte Aktionen testen, erst dann Prompt um Fähigkeit ergänzen. Allgemeine Websuche ist kein Standardtool.
