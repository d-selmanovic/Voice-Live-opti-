# Neuen Kundenagenten vorbereiten

Vorlage templates/customer-agent in eigenen Projektordner kopieren. README und AGENTS.md lesen. Agent-ID, Konfigurationsversion, Firmenzuordnung und Rechte festlegen. Keine 0.0.0-Core-Abhängigkeit erfinden: erste geprüfte Paketversion und Installation abwarten. Beispiel mit ausgeschalteter Memory und leerer Tool-Allowlist ist kein lauffähiger Agent. Zweites Profil später praktisch testen.

[Anforderungen](../requirements.md) · [Tracker](../issues.md). Anleitung beschreibt noch zu entwickelnde Runtime; keine Adapterfunktion wird behauptet.
