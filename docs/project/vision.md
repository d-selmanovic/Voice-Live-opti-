# Ziel

Activi stellt eine wiederverwendbare technische Basis für Voice-Agenten bereit. Unterschiedliche Kunden erhalten eigene Agentenkonfiguration, Firmenwissen, Kunden-Memory, Werkzeuge und Berechtigungen. Später getrennte Kundenrepositories mit geprüfter Core-Version.

Erster Fokus: ein vollständiger Browserablauf. Smalltalk gehört dazu. Die Anwendung stammt von Denis Selmanovic von activi.io. OpenAI liefert bei Nutzung seiner Dienste Modelle/API.
