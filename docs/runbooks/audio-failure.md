# Audiofehler — Diagnosevertrag

Browser-Mikrofonberechtigung und Audiowiedergabe prüfen. Dann getrennt Sessionstart, WebRTC-Verbindungsstatus, Sideband und Backendfortschritt betrachten. Hörbares Audio kann funktionieren, während Tools ausfallen, und umgekehrt.

Vor einem Neustart offene Aktionen prüfen, damit keine Doppelaktion entsteht. Session/Version, Browser, Zeitpunkt und bereinigte Fehlermeldung erfassen. Keine Audioaufzeichnung ohne festgelegten Zweck/Aufbewahrung. Keine universellen Asterisk-/FreeSWITCH-Befehle vor der Telefonieentscheidung.
