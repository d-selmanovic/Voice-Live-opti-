# Toolfehler — Diagnosevertrag

Operation, Session, Revision und Fehlerstatus ohne Secret ermitteln. Prüfen: Tool erlaubt, Identität gültig, Bestätigung gültig, Dienst erreichbar, Timeout oder unbekannter Ausführungszustand? Bei unklarem Zustand einer schreibenden Aktion zuerst externen Zustand prüfen; nicht blind wiederholen.

Im Gespräch ehrlich mitteilen, dass Ausführung nicht bestätigt ist, und passenden nächsten Schritt anbieten. Späte Antwort einer überholten Aufgabe nicht wiedergeben. Technische IDs und bereinigte Reproduktion in Issue erfassen. Konkrete Kommandos erst nach Adapterimplementation ergänzen.
